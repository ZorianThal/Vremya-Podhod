# ВРЕМЯ-ПОДХОД: Расчет долета ударной волны и действий населения

Отдельная программа оперативного расчета физических параметров долета ударной волны, времени подхода облака заражения и автоматической выработки порядка действий населения и персонала в условиях чрезвычайных ситуаций (ЧС).

Разработано по нормативам:
* **ГОСТ 22.1.01-2023** («Безопасность в чрезвычайных ситуациях»);
* **РД 52.04.253-90** («Методика прогнозирования масштабов заражения сильнодействующими ядовитыми веществами при авариях»);
* Рекомендациям ГОЧС по защите населения при радиационных, химических авариях и ядерных взрывах.

---

##  Функциональные возможности

1. **Взаимная синхронизация времени и дистанции**:
   * Определение расстояния по времени задержки между видимой вспышкой и приходом ударной волны (скорость звука в воздухе $v \approx 340$ м/с, то есть **1 км за каждые $\approx 2.94$ секунды**).
   * Возможность прямого ввода расстояния $x$ (км) с автоматическим вычислением времени прихода фронта волны.

2. **Расчет времени подхода облака заражения**:
   $$t_{\text{подхода}} = \frac{x}{U}$$
   где $x$ — расстояние до рубежа (км), $U$ — скорость ветра (км/ч). Расчет выдается с точностью до часов, минут и секунд.

3. **Советник действий человека по зонам безопасности**:
   * **Ближняя зона катастрофической опасности ($x \le 15$ км, волна за секунды)**:
     *  **ТРАНСПОРТ СТРОГО ЗАПРЕЩЕН**: выезд на автомобиле гарантированно приводит к гибели в пробках и завалах; кузов автомобиля не защищает от ударной волны и быстро проникающего радиоактивного/химического заражения.
     *  **ДЕЙСТВИЯ**: Немедленно спуститься в подвал, бомбоубежище или защитное заглубленное сооружение. Герметизировать окна и вентиляцию. Не выходить наружу до отбоя тревоги.
   * **Буферная зона ($15 < x \le 50$ км)**:
     *  **ТРАНСПОРТ ОГРАНИЧЕН**: эвакуация на авто допустима только при немедленном старте строго перпендикулярно оси сноса облака. При отсутствии машины — герметизация капитального жилья.
   * **Дальняя зона оперативной эвакуации ($x > 50$ км, время подхода измеряется часами)**:
     *  **ТРАНСПОРТ РАЗРЕШЕН И РЕКОМЕНДОВАН**: достаточный запас времени для заблаговременной эвакуации за пределы расчетного сектора поражения.

4. **Анимация тактической сцены**:
   * Отрисовка источника (эпицентра) и объекта (дома с жителями).
   * Вектор ветра и его скорость.
   * Динамическое распространение фронта ударной волны (дуга с высокой скоростью) и факела зараженного воздуха.
   * Фиксация момента удара и накрытия.
   * Настройка масштаба модельного времени ($\times 1, \times 5, \times 15, \times 60$).

##  Совместимость и компиляция

* **Платформа**: Windows Forms (.NET Framework 2.0 / 3.5 / 4.0 / 4.8 / Windows 7, 8, 10, 11).
* Не требует установки сторонних библиотек или сред разработки (Visual Studio).

### Запуск:
Просто запустите **`build.bat`**. Скрипт сам найдет штатный компилятор .NET (`csc.exe`), выполнит быструю сборку и откроет `VremyaPodhod.exe`.
